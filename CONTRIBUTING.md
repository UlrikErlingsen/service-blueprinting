# Contributing

Contributions should preserve Blueprint Signal’s central boundaries: an evidence status beside every service item, named methods with their limits, no claim that a described process was observed or measured, and fictional demo data only.

Before submitting a change:

```bash
python -m pytest
python -m ruff check .
python -m build
```

Use fictional or openly licensed test data. Do not contribute proprietary course material, customer or respondent data, or third-party content without clear redistribution rights.
